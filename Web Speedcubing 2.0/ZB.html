ZB

ZB metoda je pokročilá metoda pro skládádání kostky 3x3. Název „ZB“ pochází od autorů metody — Zbigniew Zborowski a Ron van Bruchem. Metoda vznikla jako rozšíření známé CFOP metody a jejím hlavním cílem je minimalizovat počet tahů a eliminovat rotace kostky během skládání. Díky tomu umožňuje dosahovat velmi rychlých časů, ale zároveň je náročná na naučení. ZB metoda se snaží vyřešit poslední vrstvu efektivněji než CFOP metoda. Největší rozdíl oproti CFOP spočívá v tom, že orientace hran poslední vrstvy je vyřešena už během posledního páru F2L. To znamená, že po dokončení F2L není potřeba samostatný krok OLL. Poslední vrstva se následně dokončí pomocí ZBLL, což je set algoritmů, který udělá jak orientaci a permutaci rohů, tak pertmutaci hran.

Statistiky metody:

Navrhovatelé: Zbigniew Zborowski, Ron van Bruchem,
Vznik: 2002
Počet kroků: 3
Počet algoritmů: 798
ZBLS: 305
ZBLL: 472 (+ 21 PLL) = 493
Průměrný počet tahů: 48

Kroky metody:

1. Složení kříže

2. F2L + ZBLS - Složení 3 F2L párů + ZBLS

3. ZBLL

Závěr

ZB metoda je extrémně pokročilá speedcubing metoda, která se hodí pro zkušené speedcubery, kteří chtějí posunout své schopnosti a efektivitu řešení na novou úroveň a nevadí jim naučit se obrovské množství algoritmů a složitější pattern recocnition.
